## 当前入口与指引模式（2026-10-22）

桌宠与管理客户端是不同入口：`pnpm desktop` 构建后启动独立桌宠；`pnpm desktop:client` 使用已有构建打开管理客户端及桌宠。桌宠功能页和独立工具窗不应覆盖客户端原有导航与草稿。

Windows 可双击仓库根目录的 `启动暖伴客户端.bat`，不必先启动或关闭服务器。该入口与 `pnpm desktop:client` 都会在启动前检查 Electron 运行时目录顶层的 EXE/DLL：只有被错误标为低完整性的程序文件会恢复为普通用户的 Medium 标签；不重置访问权限、不递归修改项目或用户数据，不关闭沙箱。2026-10-22 本机确认低完整性的 `electron.exe` 导致主进程创建窗口站被拒绝，低完整性的 `ffmpeg.dll` 导致隔离渲染进程加载动态库被拒绝；这发生在本地启动阶段，与服务器部署或敏感文字判断无关。运行时检查或进程早退失败会直接报告错误，不会自动改用无沙箱模式。

手机浏览器和未装配桌面桥的普通 WebView 访问共享管理页时，点击“打开桌宠”、栗栗、露米或本机原画会显示当前页面的陪伴浮层；它只服务于网页内预览，不替换 Windows 系统桌宠。Windows 客户端检测到受信任原生桥后，仍调用真实独立悬浮桌宠，页面陪伴不会改变桌面角色或采集状态。

光标指引提供连续观察和[单帧图片指引](../../docs/implementation/single-frame-guidance.md)两种路径。单帧需先选范围、截取并检查脱敏预览，确认后才发给模型；展示前重新核验本地画面。单帧提示最长五秒，不自动进入下一步；连续模式也不能在目标缺失或画面失效时沿用旧箭头。用户始终亲手点击，程序不移动系统鼠标。

默认形象是花环水獭，本地静态预览与星云实时 3D 必须明确区分。微光指引是产品品牌，栗栗、露米及其他角色名不随品牌更名。真实微信定位和操作后的连续教学仍需当前设备逐次验收，不能用隔离窗口或合成图片测试代替。

产品默认桌宠已设为用户新截图中的花环水獭（星云应用 188337），替换旧猴子。未联网时显示同款角色的本地透明静态预览；本人授权且星云返回有效资源后，切换为实时 3D。2026-10-19 已根据用户清晰截图更新本机加密凭证，并完成新应用的真实资源加载与透明 3D 渲染检查；修复桌宠 CSP 遗漏平台指定 OSS 资源域名的问题，未放宽客户端策略。验证结束已关闭远端会话，未强制重启正在使用的产品实例；原进程须在保存工作后退出重开，才会读取新凭证及策略。本机仍配置旧形象应用时禁止连接，不猜填凭证。默认值不删除已有原画或本地模型，也不自动发起可能计费的云端连接。默认形象配置、凭证安全、独立功能页、停止清理及真实接口验收边界见 `../../docs/implementation/xingyun-avatar-integration.md`。只修改桌宠形象，不重排客户端界面。

桌宠面板按独立功能页切换：功能首页只列入口，点击提问、听写、搜索、光标指引、观察、学习记录、字幕或唤醒后，仅展示对应页面；顶部“全部功能”返回首页。“面对面语音”是直接会话入口：点击即收起功能小屋，完成本人确认后，只显示桌宠头顶的对话气泡与静音、打断、结束按钮；顶部“语音陪伴”仍可浏览说明。绘画、图片问答、3D 等继续打开各自的独立工具窗。切页保留未发送草稿，不自动授权、采集或发送；离开搜索会撤销本次联网确认并停止在途搜索，离开听写页会取消未完成的听写。隐私警告与全局停止入口跨页保留。

普通悬浮态只显示桌宠形象，不再常驻提示气泡、“移动 / 语音聊聊 / 搜索 / 功能与位置”快捷文字或底部形象标签，悬停也不弹出功能提示。左键仍可打开功能页，右键或 Shift+F10 仍可打开原生菜单；展开后可使用移动把手和快捷入口。“本地静态预览 / 星云实时 3D”等真实模式说明保留在独立 3D 功能页，不把预览伪称实时。主动开启面对面语音时仍保留必要的语音气泡、静音和结束控制。

新问答消息、到期待办或需要处理的安全状态统一用模型右上方的一个小圆点提示，不自动展开、不堆叠文字框、不显示消息数量。点击圆点打开桌宠内对应页面，查看后清除该类未读提示；相同快照不会重复点亮，启动时不把历史问答当成新消息。形象读取问题只在 3D 功能页说明；本人主动开启的大字字幕与语音安全控制不受影响。

按住桌宠形象即可直接拖动，不必使用“移动”把手；静态形象、本地模型、实时 3D 和面对面语音状态均支持。移动不足 2 像素仍按单击处理，拖动释放不展开面板；单击、键盘操作和右键菜单继续保留。宿主使用受信桌宠窗口传来的有限指针坐标，起点必须位于可见桌宠内，并将窗口约束在所在屏幕工作区；不接受任意窗口边界、不操作其他软件，也不启动采集、语音或云端重连。远程输入或触摸事件不再依赖可能没有同步的系统鼠标位置。

模型内的 Canvas、视频和其他绘制子层统一将鼠标事件交给桌宠本体；指针捕获失败时由窗口级事件兜底，快速拖动只收到释放事件也不会误开面板。页面立即发送起点、首次移动和释放位置，中间更新按绘制帧合并；结束时取消未执行帧。仅旧版未携带指针坐标的请求使用 8ms 系统光标兜底。拖动以起始尺寸定位且相同位置不重复提交，避免高 DPI 边界读回的舍入误差逐帧累积；客户端管理窗口不受影响。

默认本地图片预览在普通悬浮态自动播放轻摇与呼吸动效，拖动时暂停；遵守系统“减少动态”设置。该动效不代表骨骼动画或实时 3D，不移动桌面窗口，也不发起云端连接。已连接的星云形象、栗栗及本地 3D 继续使用各自的动画，不叠加本地预览动效。

星云真实动作只在本人启用实时 3D 后可用。SDK 保留后台发布的默认交互待机状态，初始化完成后不额外覆盖它；单击模型请求互动待机，拖动不触发互动。独立 3D 页面提供待机、互动、聆听和思考四个 SDK 状态入口，具体动画由星云应用已发布的配置决定，聆听动作不打开麦克风。没有修改或删除星云后台动作；本地图片的轻摇不能替代这些动作。停止或重启后仍需本人手动确认联网，不静默恢复可能计费的会话。

独立页面浏览器回归可运行 `pnpm exec playwright test --config tests/helpers/desktop-pet-playwright.config.ts`，覆盖 400×760 与 330×520 两种窗口，并检查气泡在 320×500 与 320×360 下的布局和结束按钮；没有下载 Playwright 浏览器时，可先设置 `PLAYWRIGHT_CHANNEL=msedge` 使用本机 Edge。


在仓库根目录运行 `pnpm desktop`。当前默认启动独立悬浮桌宠，管理窗口按需打开，关闭管理不退出桌宠。启动不抓屏、不启麦、不自动接业务后端。改版差异及验收边界见 `../../docs/implementation/standalone-pet-migration.md`。

需要直接打开完整客户端时，双击根目录 `启动暖伴客户端.bat` 或运行 `pnpm desktop:client`。该入口使用已有本机运行时和构建产物，不安装、不联网、不重建；缺少产物会明确提示先执行的命令。重复运行会恢复、显示并前置已有管理窗口，不另外启动一套桌宠；窗口显示不再等待页面路由执行或桌宠加载完成。原 `启动暖伴.bat` 仍是网页开发服务器入口，不是桌面客户端。

**2026-10-23 起默认允许截图与录屏**：Windows 上 `setContentProtection(true)` 会通过 `SetWindowDisplayAffinity` 把窗口从截图 / 录屏（Snipping Tool、Xbox Game Bar、OBS 等）中排除，导致用户拍不到桌宠与管理界面。新的默认策略由 `apps/desktop/capture-visibility.cjs` 决定：**桌宠、桌宠工具小屋、语音气泡和管理界面默认可见**（可被截图与录屏捕获），屏幕观察 / 单帧采集处于活动状态时仍自动恢复保护（`management-window-visibility.cjs` 与 `standalone-host.cjs` 的 `captureActive` 逻辑），避免自身窗口污染共享画面。需要旧行为时显式传参：`--protect-pet`（桌宠侧）、`--protect-client`（管理界面）、`--protect-display`（全部）；旧的 `--pet-display-compatible` / `--client-display-compatible` 继续作为"允许捕获"别名接受。`scripts/start-desktop-client.ps1` 的 `-ProtectPet` 现在传递 `--protect-pet`，`-CompatibleDisplay` 保留为兼容别名。字幕与教学指引箭头仍始终保护，不会出现在截图或录屏里。该设置只影响本次进程，不替用户授权任何采集权限。

运行 `node scripts/test-desktop-client-visibility.mjs` 可在独立缓存资料中验证真实客户端窗口、第二进程唤起、最小化恢复与捕获保护隔离，并保存客户端自身截图；检查禁止用户桌面采集，不启用麦克风，也不会重启正在使用的产品实例。

桌宠底部“搜索”、功能页“智能查询”及右键菜单复用本机已配置的模型，与普通问答、教学共用模型实例、网关和加密凭证，不再需要 AnySearch 密钥，也不调用 AnySearch。本人确认后只发送当前手动问题；以纯文本展示“模型回答 · 未联网核验”，不把模型知识回答伪装成网页检索或来源。缺配置、鉴权失败、非法请求、取消与超时均如实提示且不重试；仅对可恢复的传输失败（网络异常、HTTP 429/5xx、响应中断）做有界自动重试（默认 2 次，可用 retryAttempts 关闭），不改变安全边界。运行路径、隐私边界和验证方式见 `../../docs/implementation/pet-anysearch.md`。

桌宠底部“语音聊聊”、功能小屋“面对面语音”和右键“面对面实时语音…”均收起小屋，进入桌宠头顶气泡会话，不弹独立聊天窗口，也不需要管理客户端。未配置专用实时语音服务但已配置文字模型时，Windows 自动采用本机中文听写、已有模型文字回答、本机中文朗读，无需新增语音账号；本人另行同意后才开启，音频不上云，但文字和少量本次上下文发送现有模型，仍需网络与额度。该模式不创建语音窗口或 Renderer 媒体权限，朗读时停麦，以按钮打断，支持气泡字幕、静音关闭麦克风和结束。显式配置的云端 WebRTC 模式仅创建隐藏隔离音频宿主，支持开口打断，不会因故障静默切换模式。结束清除气泡文字，恢复普通悬浮桌宠，不自动展开小屋。配置与真实验收边界见 `../../docs/implementation/desktop-realtime-voice.md`。

原画可以通过“画一画 → 保存本机草稿 → 预览原画桌宠 → 直接设为桌宠”直接用作独立悬浮形象，无需 AI。支持重启恢复和恢复内置形象，操作与本机验证见 `../../docs/implementation/local-original-pet.md`。开发启动优先使用最新的 `apps/web/dist`；打包版本使用包内的 `ui`，不会因为上一次打包留下的旧界面而隐藏新功能。

文字、图片与只读桌宠教学可使用当前 Windows 用户配置的真实模型网关，配置方法见 `../../docs/implementation/real-ai-provider.md`。密钥通过 DPAPI 加密保存在仓库外，仅主进程解密。管理端默认为空白本机资料，Mock 业务、固定回答、模拟登录、家属连接和生成队列已移除；未接通服务明确不可用，测试替身不进入产品。

电脑端 3D 导入已接入“我的小伙伴”：选择本地 GLB / VRM / FBX → 隔离检查 → 旋转预览 → 确认设为独立桌宠，支持原画切回与重启恢复。格式限制、安全保护及验证命令见 `../../docs/implementation/local-3d-pet.md`；真实模型与跨显卡兼容仍需验收。

- renderer 禁用 Node，开启 contextIsolation / sandbox / webSecurity。
- 管理 preload 仅暴露受限管理桥；桌宠有独立受信 IPC，主进程核对实际窗口、主 frame 和固定本地页面。桌宠指引不控制外部应用。
- `standalone-host.cjs` 独立管理观察、教学、字幕、学习记录及本地语音；锁屏/退出等必须真实停止。结束教学可保留本人仍授权的观察，关闭管理不停止桌宠。
- 大字悬浮字幕默认关闭，回答与教学步骤保留在桌宠功能页；需要时可在桌宠字幕页或右键“大字字幕”手动开启。回答、重讲和后续问题不会擅自重新开启字幕。
- 默认 session 禁止系统媒体权限与网络。本人选择后的媒体 worker 使用独立非持久 session、严格来源与权限处理，不放宽管理或桌宠 Renderer 的权限。
- 选定源捕获及本地 OCR/人脸脱敏代码已接入，但真实桌面/外部软件/系统授权尚未验收。本人授权后持续实时共享所选范围，不再按敏感文字、未知页面或无文字自动暂停；桌宠“停止共享”和托盘均可随时关闭，停止后不会自动恢复。系统撤权、来源断开或检测故障仍停止采集。按需云分析另需本人同意，并保留来源、帧哈希、时效、代次与脱敏完整性校验；大图超过云分析上限只拒绝本次分析，不中断本地共享，也不回退原图。
- 屏幕云分析仅走显式配置的主进程模型网关或原有鉴权业务端口，未配置不回退演示。本地唤醒/听写仅用离线引擎，未唤醒音频不上传，不自动改用云端。独立面对面语音另行本人同意：本地模式仅文字和少量上下文上云，云端模式 WebRTC 音频直连供应；均不与本地唤醒同时占用麦克风，不把云端语音声称为本地脱敏内容。
- 直接语音输入与持续唤醒分开：管理聊天的“语音 → 开始语音输入”及独立桌宠输入框旁的“语音输入”，都在原生窗口单独确认后立即听写，无需唤醒词。每次最多等待 20 秒，实际停麦后只回填发起输入框的草稿，不自动发送、不覆盖原文字；置信度不足时不回填候选文字、不发送模型或屏幕画面，而是提示本人靠近麦克风、放慢语速后重说；超出字数保留识别文字供本人整理。面对面本地语音同样不会把低置信听写交给文字模型，而会本地提示重说。取消、收起输入面板、页面销毁或锁屏使迟到结果失效。已有唤醒会先关闭且不自动恢复；取消尚未同意的听写不撤销此前单独授权的唤醒。宿主或 preload 升级后需重新打开客户端才能加载新入口。自动化测试使用合成识别，不代表真实麦克风或识别准确率已经验收。
- 麦克风信号提示（C2，2026-10-23 现场问题修复）：现场实测为“麦克风阵列音量正常但拾音过弱/环境太吵”（电平 31/100、`TooSoft/TooNoisy`、置信度 0.03~0.05），原实现只静默拒绝，用户看不到原因。现在语音面板显示实时电平条与可操作建议（信号过弱→靠近麦克风或提高输入音量/加强；环境噪声→关闭噪声源或改用耳机麦；语速/停顿→连贯说一句）。信号事件是建议性的：解析失败一律忽略、不改变 0.6/0.78 阈值、不代表已识别成功，音频仍只在本机处理。
- 云端语音听写（可选，默认关闭；**隐私边界变更，需本人逐次确认**）：现场证据表明内置阵列拾音只有 −27 dBFS、Windows 离线引擎对这种弱信号只给出乱码，因此在保留本机离线听写的同时新增可选云端听写。开启需本人在原生窗口确认“接受音频上传”；**每次语音输入仍单独弹窗写明本次录音会上传到已配置的模型网关**，识别结束立即丢弃、不在本机保存、不用于其它用途，识别文字仍需本人检查后亲手发送。实现：`voice/windows-cloud-dictation.ps1`（NAudio 16 kHz 单声道录音、语音门限自动停、自动增益归一到 ≈ −3 dBFS，助手自身绝不联网）+ `voice/cloud-recorder.cjs`（派生助手、读取 WAV、删除临时文件）+ `voice/cloud-dictation.cjs`（`/audio/transcriptions`，默认 `gpt-4o-transcribe`，429/5xx 有界退避重试，音频仅在请求内存留）+ `voice/cloud-dictation-settings.cjs`（开关持久化，缺省关闭）。云端失败会**回退本机离线识别**并在语音状态说明原因；未配置网关时开关不可用且面板明确提示。转写复用同一份 DPAPI 加密凭证，不额外保存密钥；录音组件 NAudio 1.10 按 MIT 随包（许可文本在包内 `voice/NAudio-LICENSE.txt`），其中录音助手脚本与 `NAudio.dll` 解包到 `app.asar.unpacked/voice/`。
- 教学运行记录与原生提醒 payload 使用 `safeStorage` 加密；不是 SQLite 整库加密。学习档案与普通待办复用本机 IndexedDB，不声称已加密。系统通知权限仍保守报告，3D、WebRTC 与真实家属音视频均未验收。C02 样例仍是隔离的合成验证，不是核心产品的外部教学证据。
- `reminder-store.cjs` 在 Electron 主进程使用内置 SQLite 保存本地提醒，当前 schema 为 `v2`，支持 v1→v2 迁移、回执/完成/取消时间持久化和回执时间顺序保护，并通过受信任 IPC 提供排程、取消、回执和完成状态；不执行系统通知或后台调度。
- `notification-adapter.cjs` 是显式调用的桌面通知预备适配器：只在注入的 Electron `Notification.isSupported()` 和权限均明确可用时创建通知，记录 `submitted`/`delivered`/`opened`/`failed` 回执，并只打开受限 `nuanban://review/...` 或 `nuanban://todo/...` 深链；已通过 `reminder-notification-bridge.cjs` 在主进程受限装配；主进程当前将权限报告为 `unknown`，不会实际创建系统通知，不能替代系统后台调度证据。
- 根目录运行 `pnpm desktop:reminder-store:check` 可复现 9 项桌面仓储测试，结果见 `docs/implementation/evidence/desktop-reminder-store-results.json`。
- 根目录运行 `pnpm desktop:notification:check` 可复现 9 项桌面通知相关预备测试（5 项适配器、4 项主进程提醒桥），结果见 `docs/implementation/evidence/desktop-notification-adapter-results.json`。
- pnpm --filter @nuanban/desktop package 只生成开发包，签名和正式发布未验收。

## 可复现开发打包

### 桌宠功能首页

点击桌宠即可打开“暖暖的功能小屋”，也可右键选择“桌宠全部功能”。光标指引位于首页首个入口，并提供固定的功能导航；观察授权、逐步核验、重讲、结束教学、搜索、实时语音、本地听写、学习记录、复习确认、字幕和本地唤醒仍在桌宠中完成。普通功能浏览不启动屏幕或麦克风、不勾选上云用途，也不自动发送问题；“面对面语音”会收起小屋并请求本次本人确认，只有同意后才开始语音，活动期间不展开功能小屋。

“学习档案”和“待办与复习”直接使用桌宠内置页面，功能卡片、右键菜单以及旧的 /notes、/todos 工具调用都不会打开客户端或工具窗。学习档案支持搜索、掌握筛选、手写及编辑笔记、本人确认掌握、记录复习和确认删除；可直接给笔记安排关联复习。待办支持新增及修改、时间二次确认、每天/每周重复、到期/已完成筛选、确认删除、查看关联笔记和记录复习后完成。切页保留编辑草稿；完成待办或复习不自动改变掌握状态。

两页复用本机 local-owner 的 IndexedDB 资料；保存采用读后版本比较事务，资料变化时保留编辑草稿并拒绝覆盖，客户端同样防止旧快照覆盖桌宠资料。首次读取不填充演示内容；教学运行核心的加密记录仍保留在“桌宠学习记录”，不会自动复制到 IndexedDB。桌宠运行时每 15 秒读取到期待办，在桌宠底部显示入口；不申请系统通知、不提供退出后的后台提醒、不自动打开页面或联网。

文字与图片问答、绘画、桌宠形象、本地 3D、亲情、账号、无障碍、隐私、能力状态和资料冲突仍可从功能首页打开桌宠工具窗。工具窗复用现有安全页面和数据端口，隐藏客户端主导航，提供“返回桌宠全部功能”；返回先确认桌宠显示，再隐藏工具窗保留草稿。桌宠工具使用独立的按需窗口，不再复用或切换客户端主窗口；工作区身份由受信窗口确定，客户端始终保留原有导航、页面与草稿，不随桌宠工具打开或返回而改变。两个窗口的 IPC 仍逐一校验实际窗口、主框架及固定本地页面，关闭工具不会退出仍驻留的桌宠。高级管理仅保留为可选入口。

AI 生成桌宠、远程账号与亲情等未接通能力继续明确标注，不因增加入口而声称可用。源码、preload 或主进程改动需要在保存工作后重新启动微光指引才能加载；开发时不会自动重启正在运行的桌宠。专项单测与界面测试使用合成端口，不代表真实屏幕定位、麦克风、混合 DPI 或远程服务已验收。

运行 `node scripts/test-desktop-pet-isolation.mjs` 可在独立缓存目录中验证真实 Electron 窗口隔离：桌宠工具不覆盖客户端导航、页面与草稿，返回仅隐藏工具，两个窗口可分别关闭与重开。该检查只操作应用自有界面，禁止用户屏幕采集，不启麦克风，不代表真实外部软件或模型服务已验收，也不会重启正在使用的微光指引。

客户端左侧“打开桌宠”可显示桌宠，并恢复最小化或隐藏的窗口，不会因此开启屏幕观察或麦克风。客户端仍打开时，“关闭桌宠”先等待观察和语音实际停止，再隐藏桌宠；可随时从左侧重新打开。仅桌宠独立运行时，关闭桌宠仍退出应用；桌宠已关闭后再关闭客户端，也会正常退出，不留下无法唤起的后台窗口。

根目录运行 `pnpm desktop:package`：先构建共享 UI，再使用已安装且版本匹配的 Electron 本机分发文件创建 ZIP 缓存，交给 Forge 打包，不在打包阶段重复下载运行时。首次安装依赖仍需确保 Electron 二进制可用。

项目 `.npmrc` 使用 Forge 要求的 hoisted 依赖布局；只影响当前工程，不修改全局 pnpm 配置。本机缓存位于根目录 `.cache/electron`，已忽略。`pnpm install --offline --frozen-lockfile` 已在本机缓存条件下执行成功。

宿主运行时只依赖 Electron/Node 内置模块，UI 已打成静态资源，因此打包明确排除 node_modules，并关闭不必要的依赖裁剪扫描，避免把 Forge/Electron 安装器等开发依赖带进应用。

PowerShell 本地检测及离线唤醒脚本通过 ASAR 的 `unpack: '**/*.ps1'` 写入真实 `app.asar.unpacked`；宿主使用固定脚本路径解析，不向 PowerShell 传入虚拟 ASAR 内路径。对应 ASAR 生成与字节校验位于 `tests/platform/desktop-external-script.test.ts`。完整开发包仍须实际打包验证，不能只凭此项测试宣称已签名或已安装通过。

该命令不签名、不创建正式安装器、不自动运行桌面应用。窗口、浮层、多屏、采集、生命周期与远程媒体仍需 C 阶段设备验证；开发包存在不等于上述能力通过。

## C02 独立验证样例

根目录运行 `pnpm desktop:lab:check` 可隐藏运行锁定 Electron 的合成窗口检查；运行 `pnpm desktop:lab:package` 可生成未签名的独立 Windows x64 包；运行 `pnpm desktop:lab` 才会打开人工验证页面。样例只允许本机固定合成窗口来源，不枚举其他窗口、不采集桌面、不启用音频，帧只统计元数据并在本机停止。真实多屏、负坐标、混合 DPI、触摸穿透与系统授权仍未验收，详见 `native-lab/README.md`。
