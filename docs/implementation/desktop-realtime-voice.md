# 桌宠面对面实时语音

> 文档同步：2026-10-22。产品显示名称为**微光指引**；[当前功能与平台边界](product-current-state.md)统一说明现行入口、已实现范围和待验证能力。本文已有测试数字与生成日期仍只对应原批次，不因文档更新自动视为重新验收。

## 使用入口

- 独立桌宠底部“语音聊聊”、功能小屋“面对面语音”和右键“面对面实时语音…”均收起功能小屋，进入桌宠头顶的对话气泡，不需要管理客户端，也不弹独立聊天窗口。
- 当前是面对桌宠的纯语音会话，不是用户视频通话，不申请摄像头，不附带观察画面、学习记录或第三方软件控制。
- 未配置专用实时服务、但已有真实文字模型时，Windows 使用本机中文听写与朗读；无需另外申请实时语音账号、设备 token 或语音供应密钥。显式配置的云端 WebRTC 模式保留，不会因故障静默切换模式。
- 点击入口后，本人必须在原生窗口单独同意所选模式的本次麦克风和上云用途。默认按钮是取消；每次重新开启都重新确认。
- 本地模式先停止原有唤醒/听写，再以不启麦、不播放声音的方式检查中文组件；云端模式先检查后端配置，再停止原有唤醒/听写。确认已停麦后，本地模式直接由主进程接管逐轮语音，云端模式仅创建隐藏的隔离音频宿主，不调用显示或聚焦。失败不使用假回答代替。
- 说完稍停，AI 回答并显示本次字幕，无需反复点击发送。两种模式都支持“打断暖暖”“静音麦克风 / 恢复麦克风”和“结束对话”。本地模式为逐轮半双工，朗读时暂停听写、只能按钮打断；云端模式支持开口打断。
- 气泡只投影本次最新用户句和暖暖回答；活动期间面板不能重新展开。桌宠只保留拖动手柄、静音/恢复、打断和结束按钮；结束后清除气泡文字并恢复普通悬浮桌宠。关闭管理页不挂断语音；全局停止、锁屏、休眠、渲染故障或退出桌宠会停止语音。每次最多 15 分钟；断线不自动重连，不恢复本地唤醒。

## 无需新增语音账号的本地方式

已有文字提问能使用真实模型时，在仓库根目录运行 `pnpm desktop`，从桌宠打开“语音聊聊”即可使用本地方式；不需要启动微光指引业务后端，也不用设置下方云端专用环境变量。文字模型配置继续复用 `real-ai-provider.md` 中的现有加密配置，不把已有模型密钥复制到语音设备 token。

- 数据路径为 Windows 本机中文听写 → 已有文字模型生成回答 → Windows 本机中文朗读。识别和朗读使用已安装的中文组件；缺少组件时明确报错，不自动安装或改用其他服务。
- **不是完全离线或保证免费的方案。**本机听写得到的文字及最多最近 6 条本次上下文会自动发送现有模型，仍需网络和该模型的额度；原始音频不发送给文字模型、不写录音文件。
- 发送前复用基础敏感文本检测，命中的隐私原文不上传、不显示；该检测并非完整脱敏，不能保证识别所有隐私，请勿说出密码、验证码或个人信息。原生确认明确说明文字上云、现有模型额度与此限制。
- 不申请摄像头，不读取屏幕、学习记录、第三方应用内容，不替用户操作电脑。文字上下文及字幕只在本次内存保留，结束清除。桌宠气泡只保留最新用户句和回答，每条最多 6000 字，不展示累积聊天列表。
- 每轮听写完成并核验停麦后才请求文字回答；置信度不足时不显示候选原文、不请求文字模型，而是在本地提示本人靠近麦克风、放慢语速后重说。朗读时不听写以避免回声。点击打断取消当前朗读后继续听写，静音取消当前轮并关闭本地麦克风和朗读，恢复继续同一会话。它不是原生全双工实时语音。
- 本地气泡模式不创建语音 Renderer、不申请 Renderer 媒体权限；听写、模型访问和朗读由受信主进程控制。字幕在主进程内存中聚合，再经桌宠 preload 投影有限文字；不传音频、密钥或原始事件。PowerShell 脚本使用固定路径，朗读文本经 UTF-8 标准输入而非命令行传递；ASAR 包中的脚本必须 unpack。
- 关闭、停止、锁屏、休眠及退出会取消当前请求，并等待识别与朗读进程实际退出；迟到回复不播放、不重新启麦。停止失败保守报告并允许重试，不将失败当作成功。网络失败不会自动重连，结束不自动恢复原有唤醒；每次最多 15 分钟。

## 可选：云端实时服务配置

仅选择云端 WebRTC 模式时，客户端持有微光指引服务地址及真实设备会话令牌：

```powershell
$env:NUANBAN_DESKTOP_API_BASE_URL='http://127.0.0.1:3000'
$env:NUANBAN_DESKTOP_API_TOKEN='<已认证设备的短期 access token>'
pnpm desktop
```

只在运行微光指引后端的终端配置供应密钥和模型，再启动后端：

```powershell
$env:NUANBAN_REALTIME_API_KEY='<语音供应密钥，不要提交到仓库>'
$env:NUANBAN_REALTIME_MODEL='gpt-realtime'
pnpm server:dev
```

模型必须由部署者明确指定为支持 OpenAI Realtime WebRTC 的 `gpt-realtime` 系列，并且账号拥有对应模型、中文转写及费用额度；配置合法不代表真实供应验收。不会读取桌面端供应 key，也不修改已有 vision/AnySearch 配置。后端密钥不进入 preload、Renderer、SDP 响应或错误消息；不要把供应 key 填入桌面设备 token 字段。Electron/后端已启动的进程不会自动读取后来更改的环境变量。

## 可选云端模式的连接与隐私边界

- 桌宠主进程通过已认证的内部桌面预览接口访问微光指引服务：`GET /internal/desktop/voice/status` 与 `POST /internal/desktop/voice/call`。这是独立桌面私有预览协议，未增加或宣称已冻结的跨端公共 `/v1` 契约。
- 状态接口不启动供应会话。建立连接时仅发送 `{offer, consent: true}`，由后端从设备认证上下文获取账号/设备，固定仅音频、无工具权限的模型配置，再调用 `POST https://api.openai.com/v1/realtime/calls`，返回 `{answer}`。不接收 Renderer 提交的供应地址、密钥、模型或系统提示词。
- 麦克风音轨经 WebRTC 直接发送给语音供应方，收到声音直接播放。**这是本人主动开启的云端实时语音，不是“按需脱敏画面上云”，语音不会先做本地内容脱敏。**原生确认明确提示这一点，用户不应说出密码、验证码等隐私；供应方按其数据政策处理，不能宣称供应侧零留存。
- 原始语音不写本机磁盘，字幕只在本次内存保留；隐藏音频页面最多保留 40 条，桌宠气泡只显示最新用户句和回答，每条最多 6000 字，结束清除；没有把对话自动存为学习笔记或上传教学历史。
- 音频窗口独立、非持久化 session，context isolation / sandbox / content protection。主页面主框架只允许音频；相机、桌面捕获、子框架和其他来源拒绝；页面 HTTP、WS、额外窗口和导航拒绝。桌宠气泡模式下该窗口始终隐藏且 `skipTaskbar`，只承担云端音频连接，不作为用户界面。字幕 IPC 仅允许固定角色和有限的 `id`、`role`、`text` 字段，桌宠控制 IPC 仅接受静音、恢复和打断。
- 接口限制请求与响应大小、连接时间、每设备并发握手，连接终止会取消在途请求；代次使迟到同意、音轨和回答失效。停止会先关闭本地音轨和 RTC，再销毁窗口并撤销会话权限；原生销毁失败保守报告麦克风未停，不把失败当成功。
- 云端模式静音关闭上行音轨并清空未提交输入，不等于释放麦克风。结束对话才停止音轨、关闭媒体连接及窗口。连接最长 30 秒等待，单次最长 15 分钟。不提供自动重连、录音、相机或自动操作，也不会在云端故障后静默降级为本地模式。
- 通用请求/认证/响应钩子只接收 `desktop_voice: true` 标记，不接收 SDP 正文；路由错误不回显供应商响应、密钥或内部堆栈。
