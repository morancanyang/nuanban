# 微光指引 · 当前产品与功能状态

更新日期：2026-10-23（Asia/Shanghai）。本页对照当前仓库中的 Windows 桌面端、Android、Web 前端、服务端和相关测试编写，是现行实现导航，不替代各功能的详细规格、带日期的验收记录或正式发布门禁。

## 产品名称与范围

产品当前显示名称为**微光指引**。旧产品名“暖伴”仍可见于旧文档文件名、包名、配置键、IPC/数据库标识、启动脚本和本机语音唤醒词中；这些历史或兼容标识不等于当前界面品牌名，也不应未经迁移评估直接改写。

当前品牌 Logo 为“鹿角光标”，已接入 Web、Windows 窗口/托盘与 Android 图标资源，来源和使用位置见[品牌资源说明](../../design/brand/README.md)。品牌标志与桌宠角色是独立配置，合并 Logo 不等于更换默认桌宠；当前默认角色仍以 `apps/desktop/default-pet.json` 的花环水獭配置为准。

跨平台入口须区分两种“陪伴”：Windows 受信任原生桥调用的是独立系统悬浮桌宠；手机浏览器、普通 WebView 或没有对应原生桥的页面调用的是当前网页内的页面陪伴。后者只渲染栗栗、露米、本机原画或当前内置伙伴，确认后可关闭，不声称拥有系统级窗口能力，也不因显示成功而改变本机桌宠设置。

核心使用形态是驻留于 Windows 真实桌面上方的独立桌宠。桌宠自身提供功能入口；管理客户端用于按需打开管理页面，不是操作第三方软件的前置窗口。Android 有独立宿主实现，但各端功能和真实设备验收进度不相同，不能据 Windows 能力推定 Android 已有同等能力。

## 功能地图

| 功能 | 当前实现与入口 | 状态及边界 |
| --- | --- | --- |
| 独立桌宠与功能清单 | Windows Electron 宿主显示透明桌宠；点击可打开功能页面，原生右键菜单提供桌宠功能入口。常见能力以桌宠内独立页面或独立工具窗打开。 | 桌宠自有 Electron 隔离测试覆盖窗口和返回流程；该测试不代表远程控制软件或真实外部应用验收。 |
| Web / 手机页面陪伴 | 手机浏览器或未装配桌面原生桥的 WebView 可从“打开桌宠”、栗栗、露米和本机原画入口确认显示当前页面陪伴浮层；浮层支持关闭，角色资源留在当前页面。 | 页面陪伴不是系统级悬浮窗，不替换手机或 Windows 系统桌宠，不开启屏幕/麦克风，不上传角色资源；真正的 Windows 悬浮桌宠仍需受信任桌面客户端。 |
| 桌面拖动、形象 | 桌宠支持直接拖动、右键设置；可使用默认花环水獭预览、栗栗、本地素材/模型等已有路径。 | 默认花环水獭可先显示本地静态预览；星云实时 3D 需本人主动连接、网络及有效本地配置。静态图或预览不能称为实时 3D。 |
| 栗栗三维模型 | “我的小伙伴” → “小鹿栗栗”提供客户端 Three.js 实时建模与旋转预览；Windows 确认后显示到透明桌宠窗口并持久化，正常重启后恢复。 | 只有小鹿本体，无背景、地面或内置动画；浏览器页面陪伴使用参考立绘，旧二维六动作保留为兼容入口。见[客户端建模说明](lili-client-model.md)。 |
| 光标/步骤指引 | 桌宠“光标指引”含授权后的连续观察路径，以及独立单帧图像指引入口。单帧流程为选择来源、截取一帧、本地检测/脱敏、本人查看预览并确认，之后才请求分析；定位结果经新本地帧复核，再由置顶指引窗口显示。 | 不会自动移动系统鼠标、点击、输入或启动微信等第三方软件。位置是短时的只读提示；目标缺失、过期、不可见或安全检查失败时不应显示伪造位置。真实连续指引仍受本机检测延迟和真实模型稳定性限制。 |
| 屏幕观察与隐私 | Windows 观察默认关闭；本人选定屏幕来源、完成系统授权并同意当前用途后，才可尝试本地观察。外发分析采用单独授权/确认和安全检查。 | 连续本地采集不等于连续上传。未知、敏感、过期、检测失败或停止未确认均应关闭或暂停外发。真实桌面测试必须由本人在实际设备完成。 |
| AI 文字、图片与查询 | Windows 可使用用户在本机安全配置的真实模型网关；图片/教学路径按各自流程处理，文字查询不等于联网搜索。 | 没有有效配置或请求失败时明确报告不可用，不回退固定/模拟回答。真实服务的额度、可用率、模型表现和账户状态不能由单测证明。 |
| 语音 | Windows 提供独立语音入口；本机唤醒词检测与本地听写/朗读路径，和显式配置后的云端实时语音路径分别管理。 | 麦克风默认关闭，启用须由本人确认。唤醒词仍为“暖伴”“暖伴暖伴”“小暖”；产品改名未改变本地识别规则。各语音路径的模型、网络和本地运行条件见语音专页。 |
| 学习资料与待办 | Windows 桌宠可进入本机学习资料和待办页面；采用用户本地存储，并有掌握确认、复习记录、草稿保护等交互。 | 本机保存不等于服务端账号、家庭共享或跨设备同步；系统级后台通知能力应以实际平台实现和设备验证为准。 |
| Android 与服务端 | Android 仓库包含普通客户端、独立桌宠宿主及本地桥接实现；服务端提供模块化 API 骨架和开发/测试存储适配。 | JVM、浏览器和 APK 编译通过都不等于 Android 真机权限、后台服务、发布数据库、远程服务或生产账号验收。 |
| 未接通能力 | 账号免密/真实认领、亲情远程协助、跨端云同步、真实生成式 2D/3D 资产、生产发布等仍需逐项核实。 | 入口、设计文档、模拟测试或服务接口骨架都不是“已可用”或“已发布”的证明；没有验收时应明确显示不可用或待验证。 |

## 指引的真实验收边界

2026-10-21 的带日期全路径记录记载：当日一次隔离运行完成了真实桌面帧、本地 OCR/UIA、脱敏、一次真实模型请求、坐标映射和 Electron 箭头绘制；也记录了长检测导致箭头空档、模型响应波动，以及未完成用户亲手操作后的连续教学验收。该结果是有范围的历史实测，不代表当前这次操作、当前微信窗口或所有桌面场景已验证。

如需重测微信指引，请先运行已构建的最新客户端，在真实桌面本人启动指引，明确选取含微信入口的区域，核对脱敏预览和发送授权；观察箭头是否落在当前微信图标上以及是否及时出现。用户本人点击目标并触发新帧核验。箭头未出现时记录界面状态、客户端时间、所用指引模式和新运行日志；不可用坐标截图或人工模拟位置充当成功。真实画面和凭证不得写入版本库。
