# 桌面真实模型与无演示运行时

> 文档同步：2026-10-22。产品显示名称为**微光指引**；[当前功能与平台边界](product-current-state.md)统一说明现行入口、已实现范围和待验证能力。本文已有测试数字与生成日期仍只对应原批次，不因文档更新自动视为重新验收。

## 当前模式与功能入口（2026-10-22）

微光指引的文字问答、图片提问、查询和屏幕指引使用不同的输入与授权路径。模型配置存在不代表已采集屏幕；普通文字问题也不会自动开启桌面监控。连续观察和[单帧图片指引](single-frame-guidance.md)分别完成来源选择、安全检查及发送授权；结果合法不代表指引窗口已经可见，仍需核对当前定位和实际渲染。当前功能边界以[产品状态](product-current-state.md)为入口，下方专项故障排查和配置要求继续保留。

## 接入范围

- 用户指定网关：`https://api.openai-next.com/v1`；模型标识保持 `gpt-6.1-sol`，不自动换模型、不向其他网关探测凭证。这是第三方网关的模型标识，不据此声称官方型号或能力已认证。
- `apps/desktop/ai-provider.cjs` 只在主进程请求固定的 `/chat/completions` 路径，禁止重定向。支持文字与已经通过本机检测、脱敏的 PNG；无自动重试、自动重连或固定回答回退。
- 管理端文字、图片端口、桌宠普通文字提问、智能查询与桌宠教学共享配置，但授权互不替代。智能查询复用同一模型实例，无需 AnySearch 密钥；当前没有网页检索工具，回答明确标注未联网核验，不伪造来源。图片需单次确认，教学仍需选屏、当次观察许可与另行上云同意；未提供画面时的桌宠文字问答不会开启屏幕或麦克风。
- 模型没有鼠标、键盘、命令执行或任意 IPC 权限。教学返回值必须通过结构、目标、代次与新帧核验；用户亲手操作，模型自称完成不会直接判定成功。

## 密钥配置

密钥不得进入仓库、前端环境变量、URL、构建产物或日志。当前 Windows 用户可运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/configure-ai-provider.ps1 -BaseUrl https://api.openai-next.com/v1 -Model gpt-6.1-sol
```

按隐藏提示输入密钥。脚本用 Windows DPAPI CurrentUser 加密，保存到 `%LOCALAPPDATA%\Nuanban\ai-provider.json`；主进程通过隐藏的本机解密进程读取。模型、网关和密钥仅用于主进程请求，不返回普通页面；服务状态 IPC 与预加载都只保留 `{ available: boolean }` 白名单，内部报错不透传。设置页只显示“智能服务”的配置状态，并保留云端发送和图片单次确认说明；已配置不代表请求一定成功。配置文件不属于项目仓库，复制给其他 Windows 用户不能直接解密。

自动部署可通过受信进程环境提供完整的 `NUANBAN_AI_BASE_URL`、`NUANBAN_AI_MODEL`、`NUANBAN_AI_API_KEY` 三项，优先于加密文件。不要把这些值写入 `VITE_*`。部分环境配置、损坏文件或解密失败都会关闭模型功能，而非回退演示。更新配置后需要正常退出并重启桌面客户端；使用 `pnpm desktop` 会先构建管理端。

## 零配置的本机模型与一键云端配置

- **本机模型自动检测**：没有环境变量也没有 `ai-provider.json` 时，主进程会依次探测 `http://127.0.0.1:11434/v1`（Ollama）与 `http://127.0.0.1:1234/v1`（LM Studio）的 `/models`，选中第一个可用模型后直接使用。装好本机模型运行时即可文字问答与本地语音对话，不需要账号、密钥或额外配置；未检测到运行时保持关闭，不会伪造回答。明文 HTTP 只对回环地址放行，云端网关仍必须 HTTPS。
- **一键云端配置**：桌宠右键菜单“配置云端智能服务（一键填 key）…”会打开一个输入窗口，默认网关 `https://api.openai-next.com/v1`、模型 `gpt-6.1-sol`，在 `API key (hidden)` 提示后粘贴本人密钥。保存成功后菜单会提示立即重启以加载新配置。密钥仍由 Windows DPAPI 加密在仓库外保存，不写入项目；此入口不替用户购买额度，也不会在未保存时启用任何模型。

密钥曾直接贴入聊天时，应到供应商控制台轮换，再通过上述隐藏输入更新本机配置。

## 输入与回答故障排查

- 桌宠输入框的插入光标不依赖模型额度或联网。即使提问接口尚未就绪，也可先编辑草稿；只有发送按钮需要等待接口与安全状态就绪。查询在途使用只读状态保留焦点，停止或失败后可继续编辑，不会自动重发。
- 正式桌面主进程通过 Electron 原生网络通道发送模型请求，沿用系统代理，不附带会话 Cookie 等自动凭证；显式模型鉴权仍只在主进程请求头中。直连连接超时不等于密钥或额度失效，不修改系统代理、不关闭 TLS 校验，也不自动重试请求。
- `401` / `403` 表示当前请求未通过网关鉴权或权限检查，不能据此判断余额或额度耗尽。请核对同一网关下的有效密钥与模型权限，通过上述隐藏输入更新本机配置，然后正常退出并重新启动客户端。`429` 在当前适配器中归为限流，也不单独证明余额耗尽。
- 文字问答失败或被中断时保留问题草稿，不显示提交成功提示，也不生成模拟回答。聚焦输入不会启动屏幕观察、麦克风或额外模型请求。

## 移除产品 Mock

- 默认业务模式为 `local`：真实 IndexedDB 仓储与空白初始资料，没有预置笔记、待办、家属、冲突或账号。
- `VITE_API_MODE=mock` 和 `VITE_MOCK_SCENARIO` 被拒绝；旧 URL 场景参数不再切换业务。
- 产品不再导入 `@nuanban/mocks`。模拟对话、登录认领、邀请接听、重连、假手机核验及生成任务入口已移除；有关合成实现仅保留于 `tests/fixtures`，不会编入管理端。
- 账号认证、远程协助、生成供应未连接时明确不可用，不以假凭证、假进度或假成功替代。本机画稿和已有 3D 模型功能保持不变。
- 新本机资料使用 `local-owner` 命名空间，不再读取旧演示账号。为避免误删用户原画和真实手工资料，旧数据不做批量破坏性删除；数据库的历史名称与旧记录兼容字段不代表仍在运行 Mock。
- 测试替身、故障注入和历史实施文档保留，用于证明失败关闭与停止隔离，而不是产品功能或正式供应证据。

## 光标指引与语音查找

- 光标指引需要本人选择真实观察来源，并单独同意必要画面按需脱敏上云。仅开启本地观察时，页面说明原因并提供重新选择与授权入口；不绕过授权启用语音查找。
- 屏幕查找先返回受理回执，再通过状态订阅显示分析进度和结果，不把等待分析显示为“正在发送”。屏幕分析默认最多等待 15 秒；超时解除忙碌状态、保留问题草稿，只允许本人手动重试，不自动重新发送。
- “语音查找并指引”仍需本次原生麦克风确认；本机识别并确认停麦后，才结合当前已授权画面发送查找请求。普通“语音输入”只填入草稿，不自动发送。两种入口均不持续上传音频。
- 观察范围、授权代次变更或停止观察后，旧的语音查找不能发送。分析期间可点击“结束教学”取消当前请求，或点击“停止观察”关闭观察；迟到的分析结果不能恢复箭头或阻塞下一次提问。
- 回归使用合成画面、模型和听写结果，覆盖受理回执、超时恢复、取消隔离及授权透传，不证明真实跨软件定位或麦克风兼容性已验收。浏览器用例为 `tests/e2e/desktop-pet-guidance.spec.ts`。

## 可见入口漏识别与追问

- 本地整屏 OCR 可能漏掉桌面上的小字标签。Windows 检测保留原始识别，再做一次最多 2 倍的本地放大补识别；放大尺寸受系统 OCR 尺寸与像素上限约束。补识别坐标映射回原始画面，同位置标签去重，不能跨识别轮次拼接文字或凭图标颜色猜坐标。
- 两轮识别的全部文字与人脸均参与隐私检查和遮盖。模型仅收到通过现有门控的安全画面或控件布局；不会因漏识别上传原图。控件列表未列出微信，只能说明本地尚未识别，不表示用户电脑上没有微信。
- 模型追问时，独立桌宠显示“回答暖暖的追问”输入框、“回答并继续”、“重新识别当前画面”和“改问其他问题”。文字或本人确认的语音回答继续原目标，保留最多三组问答；重新识别不清除补充上下文，也不伪造本人回答。等待回答时仍本地观察，但不会因画面变化反复发送追问。
- 追问回答绑定任务标识、任务代次和观察授权代次。停止、结束或切换任务后的旧回答被拒绝，发送失败保留草稿；敏感回答不发送模型。管理客户端不改动，大字字幕仍默认关闭，指引仍由本人亲手操作。
- HTTP 分析请求新增可选 `clarification_replies`；使用 HTTP 后端时需配套更新服务端，不通过丢弃回答回退到旧协议。直接模型与 HTTP 分析均保留原问题，明确画面来自已授权的 Windows 电脑。
- `node scripts/test-desktop-wechat-guidance.mjs` 使用真实 Windows OCR、合成桌面和合成模型检查“微信”补识别及箭头链路；禁止采集真实桌面并阻断 HTTP 网络。它不代表用户真实屏幕、真实模型效果或外部软件教学已验收。
