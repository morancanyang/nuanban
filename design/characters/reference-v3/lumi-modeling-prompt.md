# 小猫露米：独立角色建模提示词

版本：2026-10-24 / reference-v3。对象仅为参考图左侧的法师小猫，不含中央小鹿、右侧水獭或任何背景。本文是目标规格，不表示每项生产工序已经完成。

## 中文主提示词

以所提供图片左侧的小猫为唯一造型参考，制作一个可编辑、可自由旋转观察的独立三维角色“小猫露米”。保留象牙奶油色绒毛、蓝绿大眼、淡粉耳内和鼻头、柔和微笑、紫莓色魔法披风、金色包边与小星星刺绣、蓝绿椭圆胸针、棕色斜挎小包、蓝色细魔杖和金色星形杖头。造型是亲切聪明、乐于引导的幼态小猫，达到高端动画长片近景角色的材质与造型细腻度，而不是套上紫色斗篷的写实成年猫，也不是塑料盲盒。

**比例与整体轮廓。** 两足直立，头大、身短、手脚圆润；不计耳尖时头约占主体高度三分之一到五分之二，脸颊饱满、下颌柔软，颈部短且藏在披风领口。头不是正球体，颊部略向两侧鼓起，额顶自然连到耳根，面部中线明确但不过度拟人。躯干如柔软小梨形，胸腹奶油色绒毛自然过渡；肩、肘、手腕连续，手掌为厚实小爪子而不是人类细手。双脚稳稳落在同一水平面，趾缝轻微，不露尖爪。自身左手，即正面画面右侧，举起魔杖；另一只爪子在画面左侧自然靠近小包。尾巴从背后低位自然长出，绕向画面左侧再向上轻翘，尾根和尾身连接可信，不是独立漂浮的毛棒。

**面部与眼睛。** 双眼为明亮蓝绿、湖蓝到青玉色渐变的大椭圆眼，双眼对称但有轻微自然表情，眼距、眼线和视线方向稳定。虹膜具有放射状纤维、细碎色彩变化与深蓝绿边缘；大而柔和的深色瞳孔，避免细长锐利的攻击性竖瞳，不做玻璃球凸出眼眶。眼球、虹膜、瞳孔、角膜和薄眼睑分层建模，上下眼睑包住眼球，眼白比例克制，眼睛清澈湿润但不全眼发光。一主一次柔和高光由灯光形成，不粘贴白色巨大圆点。眉毛短而柔，偏深灰蓝，不是过粗的人类剑眉。小鼻头为温润玫瑰粉，外形圆润的小倒三角，鼻翼与鼻下沟细致；左右小小的闭口微笑，奶油色双颊口鼻区融入脸部，不做独立白色圆球凸块。两侧各三根主要胡须，纤细、渐尖、轻微弧度，根部附着脸颊，不是硬钢丝，不穿进眼睛。额顶有少量自然蓬起的柔软短毛束。

**耳部与绒毛。** 一对大而柔软、略向外张开的三角耳，耳尖圆钝而不尖锐；耳廓有厚度，内部轻微凹陷和折面，淡粉色耳内带极轻透光感。外毛为温暖象牙白，微有奶油色与浅蜂蜜色变化，不能泛灰、纯白死亮或黄泥色。面部细短毛、胸腹更柔软，脸颊侧缘和尾巴略长，脚掌和鼻周更短。毛流从额顶分向两颊、胸毛向下、尾毛沿尾身环绕；根部略深、末端稍浅，适度分束但整体整洁。使用有密度层次的可编辑梳毛，极少离散毛让轮廓真实；避免全身炸毛、硬刺、条纹噪点和粗纤维。

**紫色法师披风。** 颜色以参考的紫莓色、兰紫和少量洋红为主，暖光下仍辨认出紫色，不做高亮荧光紫。披风从肩部自然落下，正面打开，露出奶油胸腹，两侧下摆垂到脚踝上方；肩领柔软翻折、有真实厚度和受力点，背面有轻微重力褶皱，与尾巴错开。主体是细密柔软织物，近景有纱线织纹和低强度绒面反射，内衬为略浅的灰紫/玫紫。金色包边细而清楚，沿领口、前襟和下摆连续，具有线材或缝边体积，不是贴图中浮在衣服外的大金线。稀疏五角小星星刺绣，每一颗有明确五角形和略凸的线迹，密度克制、不铺满披风，不误做十字或加号。布料不能穿过手臂、包带、身体和尾巴，也不能变成硬纸板或金属斗篷。

**蓝绿胸针。** 领口正中是一颗椭圆形蓝绿宝石，饱满但不巨大，金色细边底座和小爪镶固定在织物上；宝石略透光、有体积和干净的宽高光，边缘颜色稍深，不是塑料按钮或自发光灯泡。胸针背部、金属包边及扣合位置合理。胸针应露在包带上方或自然错开，不能被包带切穿。

**斜挎小包。** 棕色软皮/皮革感小包位于画面左侧腰旁，一条细窄包带自另一肩斜跨胸前，贴合体表并经过披风合理开口；棕色从巧克力到栗棕轻微变化。包盖圆角、侧面有厚度，皮革细纹、包边、针脚、金色小扣和受力弯曲都应可见但不抢眼。不是硬方盒，不像悬浮在身体前的贴片；包带不能切进腹部、胡须或胸针。小爪子与包带或包边自然接触。

**星形魔杖。** 深靛蓝细杖身，略有倒角，长度与参考一致，握持点附近有少量金色细环。杖头为清楚的金色五角星，星角圆钝、厚度可读，表面微金属而不是镜面塑料；星心嵌一颗圆润蓝绿珠，具有干净折射或半透光泽。魔杖倾向画面右上方但不挡脸；猫爪确实包住杖身，有可辨认的掌心、圆指和接触阴影。不添加爆炸魔法、飞散粒子、巨型法术光圈或背景特效，不让星杖成为刺向观者的武器。

**灯光与交付画面。** 温暖宽柔光主光搭配中性偏冷的低强度辅光和柔和金色轮廓光，重点呈现象牙绒毛、蓝绿眼睛、披风织纹、金色刺绣、宝石和皮革的不同材质。保留高动态范围，AgX/电影式色调管理，白毛层次不发灰、不死白，宝石不过曝，金属不失去细节。全身三分之四正面展示，长焦肖像观感或正交资产相机，耳尖、尾尖、脚趾、披风下摆和杖头完整入镜，边缘留安全距离。最终只保留小猫及穿戴/握持的配件，透明 RGBA 背景，无地面、无展示台、无背景板、无文字、无水印；不把棋盘格印进图片里。

## 基础动作与绑定提示词（下一阶段制作要求）

以下内容与上面的外观提示词一起使用，是交给绑定师、动画师或后续生成工具的制作目标；当前 `reference-20261024-v3` 外观候选稿未绑定、未制作这些动画，不能把此清单当成已完成的动作资产。所有动作保留露米的奶油毛色、湖蓝眼睛、莓紫披风、胸针、挎包与星形魔杖，不添加背景、法阵或第三个角色。

### 自然感优先：有猫的注意力，不像自动招财玩具

露米保留一点猫的敏锐和好奇，但整体安静、亲近。视线先被吸引，耳朵轻轻定向，头随后微转，身体未必跟着动；不要每一帧都摇尾巴、歪脑袋或挥魔杖。基础动作服务于交流，不做连续表演，不靠大眼乱转表现“活泼”。

- 下表关键帧与角度是首版制作起点，不要求每次一模一样。待机呼吸可制作约 3.6–5 秒的 2–3 个微小变体，吸气略短、呼气略长，峰值有柔和停顿；只改变有意义的节奏，不添加随机噪声驱动骨骼。
- 眨眼与呼吸、尾巴摆动解耦，关注时可以较久不眨，放松时才偶尔轻眨；不按固定节拍连眨。瞳孔不做无缘由的放大缩小，视线先稳定注视目标，再进行很小的调整，不作高频左右扫视。
- 耳朵反应短而轻，一次关注转移最多一次轻微定向后停住，左右耳不必完全镜像；尾巴主要维持舒服的弯曲姿态，偶尔尾尖轻动，不作为匀速钟摆。胡须没有独立的大幅摆动。
- 招手一般一次轻摆，必要时第二次更小；肯定回应主要一次轻点头。头、肩、前臂、手腕和披风有先后，不在同一帧一起起停；动作结束减速收稳，留一点自然静止，不做夸张回弹。
- 披风、包和魔杖是有重量的实物，动作停下后也要逐渐停下；不能无风持续飘。倾听、招手和指引等主动作互斥，原地踏步只在明确的移动/跟随情境触发，日常待机不不停踩脚。调度与动作变体属于下一阶段要求，并非当前已实现能力。

### 骨骼、表情与运动原则

- 使用根控制器、重心/骨盆、脊柱、胸腔、颈、头、肩、上下臂、手掌、手指握持、上下腿、脚掌与脚尖骨骼，四肢有 IK/FK 切换。耳根与耳尖分别控制；尾巴沿真实曲线设置约 6–8 节柔性控制，根部连续接入骨盆，不把尾巴当成独立浮动物件。
- 眼球朝向、上下眼睑、眉毛、面颊、鼻口和闭口微笑独立控制。闭眼维持眼球体积和眼角位置，不缩放眼球；眯眼是眼睑变形而不是缩小虹膜。胡须根部跟随脸颊，末端只作极轻滞后，不能像触手一样乱甩。
- 披风领口、肩部和下摆用独立辅助控制或稳定烘焙的布料结果；胸针固定在领口结构上，包身和背带有明确挂接点及碰撞间隙，不能靠整体缩放让服装贴住角色。毛发根部须跟随皮肤/披风变形而非留在空中。
- 全部动作以 30 fps 制作，帧号从 0 开始；0–120 帧表示 4 秒、120 帧间隔，循环末帧与首帧同姿态、同切线。H 为不计耳尖和魔杖的站立身高；幅度是制作上限，需按模型实际碰撞调整。
- 魔杖始终握在角色自身左手，即正视图画面右侧；手指包住杖柄，握持点相对手掌固定。右手用于招手和指引。杖头不得穿脸、戳耳朵、扫到胸针或伸出资产安全边界；不在动作中突然换手。

### 防穿模、循环与交付验收

- 正、侧、背视角逐帧检查：耳尖不折入头部，眼睑不切角膜，胡须不穿口鼻；手掌不穿杖柄，杖头不碰脸和尾巴；披风不穿肩、前臂、尾根、包身和脚掌；背带不切进胸针或悬浮在毛发外一大截。
- 披风保留布料厚度，领口与胸针基本稳定，下摆才有较明显的延迟；动作结束后约 8–14 帧内阻尼收敛，不像橡胶布无限振荡。挎包通过真实背带挂点运动，接触身体时减幅，不穿腹部或大幅钟摆。
